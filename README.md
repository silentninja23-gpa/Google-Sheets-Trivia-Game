Step 1: Create Your Game Sheet
Open Google Sheets and click Blank to start a new spreadsheet.

Name your spreadsheet something fun (e.g., Spreadsheet Trivia Game).

Set up the visual layout so the game is easy to read and play:

Cell A2: Type Player Name | Cell B2: Leave blank for the player's name

Cell A4: Type Score | Cell B4: Type 0

Cell A6: Type Question # | Cell B6: Type 1

Cell A9: Type Question Prompt | Cell B9: Expand and merge cells B9 through E10 (this will be your big question display area).

Cell A12: Type Your Answer (A/B/C/D) | Cell B12: Leave blank (this is where the player types their answer).

Step 2: Open the Apps Script Editor
In the top menu bar of your Google Sheet, click on Extensions.

Select Apps Script. This will open a new browser tab with the code editor.

Delete any default code (function myFunction() { ... }) that appears in the editor window.
